# Colorectal Cancer Risk & Survival Prediction

## Project Overview
This project focuses on analyzing colorectal cancer patient data and predicting patient survival using machine learning techniques.

## Objectives
- Clean and preprocess the dataset
- Handle missing values
- Encode categorical variables
- Prepare data for machine learning
- Train a Logistic Regression model
- Predict patient survival
- Evaluate model performance

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model
Logistic Regression was used to predict the survival status of patients.

## Model Evaluation
The model was evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Classification Report

## Project Files
- `colorectal_cancer_prediction_test.ipynb` – Jupyter Notebook containing the complete analysis and model
- `.csv` – Dataset used for the analysis
